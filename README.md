## ▶️ Running the Projects

1. Clone the repository

```bash
git clone https://github.com/yourusername/java.git
```

2. Navigate to the project

```bash
cd java
```

3. Compile

```bash
javac Main.java
```

4. Run

```bash
java Main
```
